## Design rules (kept)

1. **No more repository rename work.** Do not recreate the repository or create another successor. Retiring `atrium-llm-enrich` is a #72 repository-management action.
2. **The record contract is unchanged.** Program id `digital-convert`; the seed contract (`doc_id`, `source.sha512`, file name, media type) is #71's, not a converter-specific schema.
3. **`/reformat` is the production API.** The repository keeps no `/extract_keywords*` compatibility endpoints.
4. **`/reformat` calls no other service; `/describe` may, when configured.** Temporal chains the stages on the AMČR route.
5. **One LLM/vocabulary implementation,** in `atrium-keyword-extract`. The direction is one-way: keyword code → keyword-extract, converter code → digital-convert.
6. **Image convention:** `…-api` production, `…-digital` batch/CLI; `digital-docling` stays local and unpublished.
