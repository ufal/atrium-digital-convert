## Context

The 10-09 run converted all 15 documents. The asks were answered, with two gaps the samples exposed:

- **Large files:** with `MAX_UPLOAD_MB` raised, the 156 MB file is accepted. The default is 200 since 10-14.
- **Damaged text marked before `/describe`:**
  - `none` and `ocr` pages were flagged.
  - Two extraction defects passed as `digital` text, unflagged: words split at Czech letters set in a second font, and glyphs without a Unicode mapping written as `(cid:N)`.
  - A page number over a scan was `digital` too.

The cluster run also failed on its own side: stale sibling checkouts, page-classification not starting, Docling failing on every file. So stage 62 (a page type for every page), which the stamp-over-scan threshold was meant to rest on, has not run.
