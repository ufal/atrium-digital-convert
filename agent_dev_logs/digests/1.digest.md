## 🎯 Goal

Make the repository the single-purpose **born-digital conversion stage**:
* born-digital input → `atrium_document` record; program id `digital-convert`;
* production HTTP surface `POST /reformat` (record; Markdown on request; `paradata`), plus the optional `POST /describe` (#2);
* no keyword/LLM service, code or image here; the one LLM/vocabulary implementation lives in `atrium-keyword-extract`;
* the service takes part in the six-stage architecture and the record/paradata contract.
