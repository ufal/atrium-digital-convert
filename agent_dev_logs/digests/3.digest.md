## 🎯 Goal and the decision

Decide what reaches the LLM for document understanding: enough structure and spatial provenance for page-level grounding, without tying the system to one parser.

| Layer       | Representation                                                                                                                                   | Role                                                                                               |
|-------------|--------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------|
| Source      | PDF, office files, ALTO/PAGE, TEITOK                                                                                                             | what the archive supplies; the spatial truth                                                       |
| Canonical   | `atrium_document` JSON                                                                                                                           | everything the stages add; entities and keywords live here                                         |
| Model input | annotated Markdown (`json_to_md.py`, `xml_to_md.py --format layout`, one cue vocabulary in `layout_md.py`; profiles `full`/`standard`/`minimal`) | headings, paragraphs, lists, tables, footnotes, plus page, box, header/footer and `NEEDS_OCR` cues |
| Fallback    | TXT                                                                                                                                              | when no structure can be rebuilt                                                                   |

HTML+CSS stays an intermediate (token cost). Raw XML is too verbose for every call. DOCX/PDF are inputs. page-classification steers *treatment*; it does not choose a second format.
